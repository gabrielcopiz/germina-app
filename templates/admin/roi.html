¿Cómo se calcula el ROI?

Cada tipo de tarea tiene un tiempo estimado de trabajo manual asignado (por ejemplo: responder una consulta = 3 minutos, dar de alta un socio = 15 minutos). Cuando Germina automatiza o prepara esa tarea, ese tiempo se suma al ahorro acumulado.

El valor económico se calcula usando un costo de referencia de USD {{ valor_hora_usd }}/hora de trabajo administrativo.
